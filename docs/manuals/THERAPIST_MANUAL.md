# Panduan Terapis RehabTrack

## Masuk

Gunakan email dan kata sandi akun terapis. Setelah masuk, halaman **Pasien Saya** menampilkan pasien yang ditugaskan.

## Review mingguan

1. Pilih pasien untuk membuka detail.
2. Gunakan pilihan latihan untuk membaca tren ROM delapan minggu.
3. Tinjau log sesi dan catatan pasien.
4. Gunakan **Mulai video call** untuk membuka ruang Zoom/Google Meet eksternal.
5. Tambahkan arahan di bagian **Catatan mingguan** dan pilih minggu program.

Data seed demo memakai akun fiktif berikut:

- Email: `terapis.demo@example.com`
- Kata sandi: `demo-password-123`

Ganti kredensial demo sebelum penggunaan pilot. Jangan memasukkan data pasien nyata ke environment development.
