# STROKE-GEMASTIK

This is a monorepo for a stroke recovery mobile app (Gemastik competition project).

- `client/` - React Native (Expo) mobile app for patients. Active client.
- `mobile/` - Flutter app, planned replacement for `client/`. No Flutter code yet.
- `server/` - Node.js backend
- `therapist-dashboard/` - therapist web dashboard
- `docs/` - documentation (`engineering/`, `product/`, `planning/`, `setup/`, `manuals/`)
- `references/` - local reference repositories, gitignored

Phase 2 plans live in `docs/planning/phase2/` and `docs/planning/phase2-execution-plan.md`.

The Flutter migration is planned in `docs/planning/phase2-execution-plan.md` section 14. `client/` remains the active client until Flutter reaches feature parity and passes device testing.
